## Требования и алгоритм
- Реализовать библиотеку парсер-комбинаторов `Parser a = Parser { runParser :: String -> Either String (a, String) }` с инстансами `Functor`, `Applicative`, `Monad`, `Alternative`.
- Примитивы (`item`, `satisfy`, `char`, `string`, `spaces`, `eof`) и комбинаторы (`many1`, `sepBy`, `between`, `token`, `symbol`, `number`) для построения парсеров.
- AST JSON: `JNull | JBool | JNumber | JString | JArray | JObject`.
- Парсер JSON-значений: null/bool/number/string/array/object с проверкой конца ввода.
- Класс `FromJSON` для базовых типов, `Maybe`, `Either`, списков.
- Auto-deriving: класс `JsonRead` + generic-обход `GJsonRead`, разбирающий записи по именам полей в `JObject`; общий инстанс `FromJSON` для generic-типов.
- Тесты демонстрируют авто-деривацию для вложенных типов (`Student` с `Maybe Point`).

Алгоритм парсинга: комбинируем примитивы через аппликативы/альтернативы; для JSON объектов ищем поля по именам селекторов, для массивов парсим список значений, для строк обрабатываем escape-последовательности, числа читаем со знаком/дробью/экспонентой.

## Реализация (основные файлы)
- `src/Parser/Core.hs` — ядро парсера и инстансы.
- `src/Parser/Combinators.hs` — примитивы/комбинаторы, парсер чисел.
- `src/JSON/AST.hs` — тип `Json`.
- `src/JSON/Parser.hs` — парсер JSON → AST.
- `src/JSON/FromJSON.hs` — преобразование AST → Haskell-типы.
- `src/JSON/Generic.hs` — generic-деривация `JsonRead` и `FromJSON`.
- `test/Spec.hs` — автотесты на парсинг и авто-деривацию пользовательских типов.

## Ввод / вывод
- Вход: строка JSON.  
- Выход: либо ошибка (`Left String`), либо разобранное значение (`Right Json` или `Right a` при `JsonRead`/`FromJSON`).  
- Пример (CLI `Main`): парсинг `{"msg":"hello","nums":[1,2,3]}` → вывод AST; парсинг `Point`, `Student`, `...` через `parse`.

## Выводы
- Монадический стиль написания парсеров упрощает создание сложных парсеров, давай базис в виде простейших парсеров и возможность его комбинировать с помощью комбинаторов (реализовав инстансы для `Functor`, `Applicative`, `Alternative`, `Monad`...);
- Generic-обхяд типов позволяет автоматизировать сопоставление полей типа и выводить изоморфные данному типы;
- Небольшой набор комбинаторов покрывает весь JSON, включая вложенные пользовательские типы с `Maybe`/`Either`;
